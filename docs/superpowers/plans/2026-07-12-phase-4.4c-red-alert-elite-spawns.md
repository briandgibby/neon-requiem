## Goal

At RED alert, reinforcement resolution can add corporation-specific elite NPCs using existing `MobTemplate.eliteOnly` and `MobTemplate.corporationId` fields.

This keeps elite response tied to the same safe-zone and reinforcement timing gates as ordinary automated hostile spawns.

---

## Implemented

- `MobRepository.findEliteByCorporation(corporationId)` returns an elite template for the room owner behind the Combat domain service seam.
- `Room.factionOwner` is the current corporation/facility owner source for the vertical slice.
- `CombatReinforcementSystem` uses a narrow combat-domain mob catalog and the World room lookup to read `factionOwner`.
- RED-alert reinforcement resolution spawns the ordinary security guard plus a matching elite template when one exists.
- YELLOW/non-RED reinforcement resolution does not query or spawn elites.
- Elite spawns use `MobFactory` with hostile AI state, so they participate in the Phase 4.4B mob AI loop.
