## Goal

Let a physical teammate actively shield a jacked-in decker's vulnerable body from hostile mob AI.

---

## Implemented

- Added `GuardExecutor` for the existing `guard` combat move.
- `guard` marks the actor's `CombatStatusComponent` as `guarding` and records the guarded target entity.
- Guarding requires actor and target to be in the same physical room.
- Guarding a jacked-in decker uses `DeckerComponent.physicalRoomId` so a teammate can shield the decker's body while the decker's ECS position is in the Matrix.
- `MobAiSystem` redirects attacks aimed at a jacked-in decker's physical body to a living guard in the same physical room.
- Guarded targets keep their AI target identity; only the actual attack target is intercepted.
